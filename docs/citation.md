# Citing Morana

Machine-readable citation metadata is available in
[`CITATION.cff`](https://github.com/tannhorn/morana/blob/main/CITATION.cff).
The version DOI for Morana 0.1.0 is
[10.5281/zenodo.22681316](https://doi.org/10.5281/zenodo.22681316).
The [all-versions DOI
10.5281/zenodo.22681315](https://doi.org/10.5281/zenodo.22681315) always
resolves to the latest Morana release.

When citing Morana, use the version DOI corresponding to the version used so
the citation identifies the archived source rather than the changing
development branch. Use the all-versions DOI when referring to the project or
when the citation should follow the latest release.
